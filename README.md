This project is a space-themed arcade game where players control a laser cannon to defend themselves against waves of alien invaders.

The game includes several exciting features, such as a customizable frame rate, dynamic enemy movement, and responsive player controls. At the beginning of the game, players enter their names, and their scores are recorded on a high-score leaderboard.

The game loop continuously updates the game state by processing player input, spawning enemies, detecting collisions, and calculating scores. When the game ends, the player's final score is saved along with their name, allowing progress and high scores to persist across multiple sessions.

In addition to providing an enjoyable gaming experience, this project serves as a practical learning resource for Python programming concepts, including animation, event handling, and file input/output (I/O).
